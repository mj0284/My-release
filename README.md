# My-release

## Trainer Menu — Cyberpunk 2077 트레이너 메뉴

게임 중에 **Insert** 를 누르면 뜨는 트레이너 메뉴 모드. 키 바인딩 설정 없이 설치만 하면 바로 Insert 로 열린다.

> **검증 상태**: 이 저장소에는 게임이 없어서 **실제 게임 안에서는 아직 한 번도 실행해 보지 못했다.**
> 사용하는 함수 이름/시그니처는 CET·Codeware 소스와 게임 2.x 스크립트 덤프로 하나씩 대조했고,
> 가짜 게임 환경에서 도는 자동 테스트(51개)는 전부 통과한다. 그래도 첫 실행 때 안 되는 기능이 있을 수 있다.
> 문제가 생기면 `TrainerMenu.log` 내용을 알려 주면 된다 (아래 [문제 해결](#문제-해결) 참고).

### 필요 모드 (넥서스)

| 모드 | 용도 |
|---|---|
| [Cyber Engine Tweaks](https://www.nexusmods.com/cyberpunk2077/mods/107) 1.38.0 이상 | Lua 실행, 화면 표시, 게임 함수 호출 |
| [RED4ext](https://www.nexusmods.com/cyberpunk2077/mods/2380) | Codeware 가 요구함 |
| [Codeware](https://www.nexusmods.com/cyberpunk2077/mods/7780) | Insert·방향키 입력 받기 |

게임 버전은 2.x (패치 2.0 이후) 기준.

Codeware 가 없어도 모드는 로드된다. 다만 Insert/방향키가 안 먹고, CET 오버레이를 열었을 때 메뉴가 같이 떠서 마우스로만 쓸 수 있다 (노클립은 불가).

### 설치

이 저장소의 `bin` 폴더를 게임 설치 폴더(`Cyberpunk 2077`)에 그대로 덮어쓴다. 결과적으로 아래 위치에 들어가면 된다.

```
Cyberpunk 2077/bin/x64/plugins/cyber_engine_tweaks/mods/TrainerMenu/
├── init.lua
└── modules/
```

`tests` 폴더는 개발용이라 게임에 넣을 필요 없다.

이전 버전(`mods/F5Trainer` 폴더)을 넣어 둔 적이 있으면 그 폴더는 지운다. 남겨 두면 트레이너가 두 개 뜬다.

### 조작

| 키 | 동작 |
|---|---|
| **Insert** | 메뉴 열기 / 닫기 |
| ↑ ↓ (넘패드 8 / 2) | 항목 이동 |
| ← → (넘패드 4 / 6) | 값 조절, 켜기/끄기 |
| Enter (넘패드 5) | 선택 / 실행 |
| Backspace (넘패드 0) | 뒤로 / 닫기 |

넘패드 조작은 NumLock 이 켜져 있을 때 기준이다. 꺼져 있으면 넘패드 0 이 Insert 로 인식돼서 메뉴가 닫힐 수 있다.

CET 오버레이가 열려 있을 때는 키 대신 마우스를 쓴다: 클릭 = 선택·다음 값, 우클릭 = 이전 값, 오른쪽 위 `<` / `X` = 뒤로 / 닫기.

### 기능

**플레이어**
- 무적, 무한 스태미나, 무한 RAM, 무한 산소, 무한 탄약
- 소지 무게 무제한, 체력/스태미나/RAM 즉시 회복
- 이동 속도 배율 (x0.5 ~ x5.0)
- 노클립: WASD 이동, Space 상승, Ctrl 하강, Shift 가속 (속도 2 ~ 80 m/s)

**돈 / 성장**
- 돈 +10,000 / +100,000 / +1,000,000
- 레벨 +1 / +5, 스트리트 크레드 +1 / +5 (상한은 게임 값 따름)
- 특성 포인트, 퍽 포인트, 렐릭 포인트 추가

**아이템 지급**
- 탄약, 제작 부품, 퀵핵 부품

**월드**
- 시간 변경 (아침 / 정오 / 저녁 / 자정 / +1시간) — 날짜는 유지하고 항상 앞으로만 넘긴다
- 게임 속도 (x0.1 ~ x2.0)
- 수배 해제, 경찰 비활성화

**텔레포트**
- 지도에서 추적 중인 핀으로 이동
- 위치 저장 / 불러오기 5칸 (게임을 껐다 켜도 유지)

**설정**
- 언어 (한국어 / English), 메뉴 키 변경 (F1 ~ F12, Insert, Delete, Home, End, PageUp, PageDown)
- 메뉴 키가 F5 일 때 퀵세이브 막기

### 저장

메뉴에서 바꾸는 건 **전부** 모드 폴더의 `config.json` 에 바로 저장되고, 다음에 게임을 켜면 그대로 복원된다.

- 켜고 끄는 치트 (무적, 무한 스태미나/RAM/산소/탄약, 소지 무게, 노클립, 경찰 비활성화)
- 이동 속도 배율, 게임 속도
- 언어, 메뉴 키, 퀵세이브 막기 옵션, 노클립 속도
- 텔레포트 저장 위치 5칸

```
Cyberpunk 2077\bin\x64\plugins\cyber_engine_tweaks\mods\TrainerMenu\config.json
```

- 저장된 치트는 **어느 세이브를 불러오든** 게임에 들어가는 순간 다시 켜진다. 끄고 싶으면 메뉴에서 끄면 그것도 저장된다 (메인 메뉴에서 꺼도 된다).
- 노클립은 Codeware 가 없으면 복원하지 않는다 (조작할 수 없으므로). 저장 값은 남겨 두니 Codeware 를 다시 깔면 돌아온다.
- 처음엔 파일이 없고, 설정을 하나라도 바꾸면 생긴다. 메모장으로 고쳐도 되는데 잘못된 값은 무시되거나 범위 안으로 맞춰진다. 고친 내용은 게임을 다시 켜거나 CET 의 "Reload all mods" 를 해야 적용된다.
- 처음 상태로 되돌리려면 게임을 끈 상태에서 `config.json` 을 지우면 된다.

### 메뉴 키를 F5 로 바꿀 때

기본 키인 Insert 에서는 게임의 F5 퀵세이브를 전혀 건드리지 않는다.

`설정 > 메뉴 열기 키` 를 F5 로 바꾸면 게임 기본 퀵세이브 키와 겹쳐서, 그대로 두면 메뉴를 열 때마다 퀵세이브가 된다.
그래서 메뉴 키가 F5 인 동안에는 **F5 로 들어온 퀵세이브를 막는다** (일시정지 메뉴의 저장은 그대로). 막고 싶지 않으면 `설정 > 메뉴 키가 F5 일 때 퀵세이브 막기` 를 끄면 된다.

### 주의

- **무적**을 켠 채로 진행하면 플레이어가 피해를 받아야 넘어가는 연출에서 퀘스트가 멈출 수 있다. 그럴 땐 끄고 다시 시도. 치트는 저장되므로 다음 실행 때도 켜진 채라는 점을 기억할 것.
- **노클립**을 켠 채로 끝내면 다음에 불러왔을 때도 공중에 뜬 상태로 시작한다. 걸을 수 없으면 메뉴에서 노클립을 끄면 된다.
- **경찰 비활성화**는 게임 세이브 파일에도 기록된다. 켠 채로 저장한 뒤 모드를 지우면 그 세이브는 경찰이 꺼진 채로 남는다. 모드를 지우기 전에 끄고 저장할 것. (모드가 설치돼 있는 동안은 불러올 때마다 메뉴의 켜짐/꺼짐 상태에 맞춰진다.)
- **레벨 / 포인트 / 돈**은 되돌리는 기능이 없다. 쓰기 전에 세이브를 따로 남겨 두는 걸 권한다.
- **노클립**으로 맵 밖이나 건물 속에서 끄면 낙하하거나 끼일 수 있다. 무적과 같이 쓰거나 저장 위치로 빠져나오면 된다.

### 문제 해결

- **Insert 를 눌러도 안 뜬다** — CET 콘솔에 `[TrainerMenu] ... loaded` 가 찍혔는지 확인. `Codeware missing` 이 같이 나오면 Codeware/RED4ext 가 설치되지 않았거나 게임 버전과 안 맞는 것. 급하면 CET 오버레이 > Bindings 에서 `Trainer Menu: open / close` 에 키를 직접 지정해도 열 수 있다.
- **Insert 를 누르면 CET 오버레이도 같이 뜬다** — CET 오버레이 키가 Insert 로 잡혀 있는 것. 둘 중 하나를 다른 키로 바꾼다 (트레이너 쪽은 `설정 > 메뉴 열기 키`).
- **한글이 `?` 로 나온다** — CET 설정의 Font > Language 를 Korean 으로 바꾸거나, 메뉴 `설정 > Language` 를 English 로 바꾼다 (맨 아래 메뉴의 첫 번째 항목에서 → 키).
- **특정 기능만 안 된다** — `mods/TrainerMenu/TrainerMenu.log` 에 `... failed:` 줄이 남는다. 그 줄을 알려 주면 고칠 수 있다.

### 개발

```
luajit tests/run_tests.lua
```

`tests/cet_mock.lua` 가 CET·Codeware·게임 API 를 흉내 낸다. 정의되지 않은 함수나 열거형 멤버를 부르면 에러가 나도록 만들어서 이름 오타를 잡는다. `tests/vendor/json.lua` 는 CET 에 들어 있는 것과 같은 [rxi/json.lua](https://github.com/rxi/json.lua) (MIT).
